# EpiData Mac 平替（epidata4mac）

在 macOS 上替代 Windows EpiData Entry 的本地网页版工具：**通用解析任意 EpiData
项目的 .qes / .chk / .rec 三件套**，提供问卷版面录入（实时校验、跳转、REPEAT 带值）、
Excel 式全字段浏览与修改、EpiData 兼容导出（text / xlsx / csv）。

- 仅监听 `127.0.0.1`，不对外网开放
- 所有写入操作前自动备份（`.bak` / `.deleted-*.bak`）
- 写回的 .rec 与原格式完全一致（GBK 编码、CRLF、`!` 行终止符、78 字符断行），
  Windows EpiData 可直接打开、合并

## 环境要求

| 项目 | 要求 |
|---|---|
| Python | ≥ 3.10 |
| 依赖 | 仅 `openpyxl`（xlsx 导出；其余功能均为标准库） |
| 操作系统 | macOS / Windows / Linux 均可运行；文件夹与文件选择对话框依赖 macOS osascript |

## 安装与启动

```bash
pip install -r requirements.txt
python app.py
```

启动后自动打开 `http://127.0.0.1:8317`（端口占用时自动 +1）。
macOS 用户也可双击 `启动.command`（内含本机 conda 环境路径，可按需修改）。

## 功能说明

### 1. 打开项目

- 点「📁 选择文件夹…」或「📄 选择 .rec 文件…」（macOS 原生对话框，服务端调起，
  能拿到真实路径），或手动输入目录后点「扫描目录」。
- .qes / .chk 同目录同名自动配对；目录中存在多个时可在下拉框手动指定。
  - **.rec 必需**：字段结构以 .rec 定义行为准（0 条记录也可以）。
  - **.qes 可选**：缺失或对不上时自动退化为平铺表单并提示。
  - **.chk 可选**：遇到未支持的命令会警告但不阻断。

### 2. 录入

- **顺序录入**：严格按问卷顺序逐格进行，REPEAT 带出的已有值不跳过，
  Enter 逐格前进；JUMPS / AFTER ENTRY 条件跳转仍生效。
- **输满自动跳格**：数值/日期等字段输满定义位数后自动进入下一格。
- **自动格式化**（确认跳转时按字段定义执行）：
  - 带小数的字段（如 `###.#`）自动补齐小数位：`170` → `170.0`；
  - 整数字段自动去前导零：`0012345678` → `12345678`、`00` → `0`；
  - 日期字段输入 `20240115` 自动变为 `2024/01/15`。
- **实时校验**：范围、合法值、必填、日期与数值格式不符时**立即弹窗拦截**
  （RANGE 与 LEGAL 同时出现时，LEGAL 是范围外的附加合法码，如 `RANGE 1 2` + `LEGAL 9`
  表示 1、2、9 都合法；只有 LEGAL 时才是穷举白名单）
  （必填空着离开当场拦截；被跳转合法跳过的必填允许留空，与 EpiData 语义一致）。
- **回溯即修改**：方向键回到已填格子时内容自动全选，直接打字即覆盖。
- **记录导航**：工具栏 ◀ 上一份 / 下一份 ▶ / ＋ 新增 / 删除（删除前生成完整
  备份 `.deleted-*.bak`），查看其他问卷不影响正在录入的草稿，
  「↩ 回到当前正在录入的问卷」一键回原位续录。
- **底部状态栏**：实时显示当前格子的字段名、类型与范围、存储长度。
- **自动赋值**：`.chk` 的 AFTER ENTRY 里 `IF pos("1",a04) <>0 THEN LET a04q1=1 ELSE …`
  这类规则在确认字段时自动填好目标字段（如 A04 录 `234` → A04Q1-6 自动填 `2/1/1/1/2/2`），
  随后按裸 GOTO 跳到指定字段。
- **录入计时**：录入页左上角悬浮显示当前这份问卷的有效用时（新问卷从 00:00 起）；
  录入页内任意操作（打字、按键、点击、滚动）都会重置 5 秒空闲窗口，无操作 5 秒
  自动暂停并显示「已暂停」，再操作即继续；切到其它面板、打开弹窗、查看历史记录
  时暂停。下方「平均录入时间」= 本次会话累计有效录入时间 ÷ 当前 .rec 记录数
  （含历史记录，打开即有值），换 .rec 文件重新统计。计时仅存于内存，**不写入 .rec**，
  刷新页面后清零。

### 3. 草稿与保存

- **草稿续录**：每填一格自动写入伴生文件 `<rec名>.draft.json`（半条记录不写入
  .rec，以免产生空记录）；中途退出后再次打开同一 .rec 会询问是否从原位继续；
  整份问卷保存进 .rec 后草稿自动清除。
- **保存**：直接写入 .rec（首次写入自动备份 `.bak`），保存后自动开始下一条。

### 4. 浏览

- Excel 式全字段表格：全部记录 × 全部字段一起预览，**表头行与行号列冻结**、
  隔行底纹、列头悬停显示题目全文、双击记录进入编辑。
- 支持任意字段内容的全文过滤。
- **「检查历史数据并规范化」**：扫描全部记录的数值字段（去前导零、按定义小数位
  格式化），先报告差异与问题、经确认后执行；无法解析或超格式的值保持原样并报告，
  绝不破坏历史数据。

### 5. 导出

导出面板完整复刻 Windows EpiData 的「将REC文件导出为text文件」对话框，
**记录范围 / 字段选择 / 编码对三种格式全部生效**：

| 项目 | 说明 |
|---|---|
| 记录范围 | 全部记录，或记录号起止区间 |
| 字段选择 | 全选 / 不选 / 悬停显示题目 / 点选锚点后「此字段及之前 / 之后」批量选择 |
| 记录过滤器 | 简单条件表达式，如 `q3=2 and q1=1`（and / or 组合） |
| 文本选项 | 文本括号 `"`、字段分割符（; , Tab 空格）、首行书写字段名（仅 text） |
| 导出编码 | GBK（兼容 GB2312，Windows 默认）/ UTF-8 / UTF-8 带 BOM（仅 text 与 csv） |
| 导出位置 | 「选择文件夹」+「文件名」，扩展名随格式自动切换 |

导出列顺序与 EpiData 原生导出逐列一致（测试锁定）。

## 数据兼容性

- 写回的 .rec 保持原格式（GBK 编码、CRLF、`!` 行终止符、78 字符断行），
  Windows EpiData 可直接打开与合并。
- 文件头兼容 `616 1 VLAB` 和 `959 1`（省略 VLAB）两种写法；.rec 与 .chk
  字段名大小写不一致时（如 .rec 全大写、.chk 全小写）自动按 .rec 名字对齐，
  校验规则与跳转不会失效。
- 数值字段按 EpiData 原版行为规范化存储（整数字段去前导零、浮点字段按定义
  小数位补齐），导出结果与原版 EpiData 导出逐列一致。

## 文件格式（逆向结论，已字节级验证）

详见 `epirec.py` 模块 docstring。要点：

- **.rec**：纯文本（GBK/CRLF）。首行 `<定义行数> 1 VLAB`；N 行字段定义
  （`#`/`_` 前缀 + 行列/类型/宽度 + 问题文本，`_labelN` 为标题行不占记录空间）；
  数据区每条记录固定「各字段宽度之和」字节，按 78 字符断行、每行以 `!` 结尾。
  数值右对齐补空格、字符串左对齐补空格。
- **.qes**：问卷版面。`{字段名}` + `#`/`_`/`<yyyy/mm/dd>` 占位符；无花括号的
  占位符由 EpiData 按行首单词自动命名（如 `Z8 录入日期：<yyyy/mm/dd>` → z8），
  兜底名 `fieldN`。
- **.chk**：每字段一块的缩进规则块。

字段与版面的绑定规则：.rec 定义行的行号 → .qes 行号，行内从左到右按宽度对齐。

## 测试

测试需要一份真实的 EpiData 项目数据（.rec/.qes/.chk），通过环境变量指定：

```bash
export EPIDATA_TEST_DATA=/path/to/your/epidata/project   # 含 .rec/.qes/.chk
python tests/test_roundtrip.py    # .rec 字节级还原 + 与原版导出 txt 交叉核对
python tests/test_qes_chk.py      # 绑定与规则解析自检
python tests/test_save_flow.py    # 端到端增改删存（在 /tmp 副本上进行；需服务已启动）
python tests/test_export.py       # 导出与原版 EpiData 导出逐列比对（只读；需服务已启动）
```

test_export 支持两个可选环境变量：`EPIDATA_REF_TXT`（原版 EpiData 导出的 txt，
用于表头顺序比对）、`EPIDATA_REF_XLSX`（人工汇总的 xlsx，用于逐格比对）。
未设置数据目录时测试自动跳过。

## 已知限制

- .chk 支持：RANGE（含 `-INF`/`INF` 与日期区间）、LEGAL（逗号/区间写法、
  `LEGAL USE 字段`）、COMMENT LEGAL（块、`USE 字段` / `USE 标注块`）、
  MISSINGVALUE（字段级、`MISSINGVALUE ALL`、字段清单）、MUSTENTER、REPEAT、
  JUMPS（含 `JUMPS RESET`、`SKIPNEXTFIELD` / `WRITE`）、AUTOJUMP、
  BEFORE/AFTER ENTRY 的 IF..THEN..ELSE、GOTO、LET、CLEAR、CHECK、HELP；
  BEFORE RECORD 的 LET / CLEAR，AFTER RECORD 的 LET / CHECK / GOTO（阻止保存）；
  COMMENT LEGAL 引用外部
  .rec 查询表（按 KEY 1 / KEY 2 读取值→标签）；表达式与常用函数（算术、比较、
  逻辑、字符串、日期、`TODAY`、`Sum/CountMissing` 等，`IGNOREMISSING` 也生效）。
  仅 RELATE / BACKUP / EXECUTE / LOAD 等桌面集成与 UDF（DLL）命令不执行，
  会列入警告，不影响打开与录入。
- 不支持从 .qes 新建空 .rec（打开已有 .rec 即可，0 条记录也行）。
- 双录入核对未实现（按需求暂缓）。
- 文件夹与文件选择对话框依赖 macOS osascript；其它系统请手动输入路径。
