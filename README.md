# EpiData Mac 平替

在 Mac 上替代 Windows EpiData Entry 的本地网页版工具：**通用解析任意 EpiData 项目的
.qes / .chk / .rec 三个文件**，提供问卷版面录入（实时校验/跳转/REPEAT 带值）、
浏览修改（Excel 式全字段表格）、导出（text / xlsx / csv）。

仅监听 `127.0.0.1`，不对外网开放；写入前自动备份。

## 启动

- 双击 `启动.command`（macOS，内置 conda 环境路径，可按需修改），或
- `python app.py`（标准库实现；xlsx 导出需要 openpyxl）

自动打开 `http://127.0.0.1:8317`（端口被占用时自动 +1）。

## 使用

1. **打开**：点「📁 选择文件夹…」（macOS 原生对话框，服务端调起、能拿到真实路径）或
   「📄 选择 .rec 文件…」直接打开；也可以手动输入目录路径后点「扫描目录」。
   .qes / .chk 同目录同名自动配对；目录里有多个时可在下拉框手动指定。
   - .rec 必需（字段结构以 .rec 定义行为准，0 条记录也可以）
   - .qes 可选：缺失/对不上时自动退化为平铺表单并提示
   - .chk 可选：遇到未支持的命令会提示但不阻断
2. **录入**：**严格按问卷顺序逐格录入**（与原版 EpiData 一致，REPEAT 带出的已有值
   不跳过，Enter 逐格前进；JUMPS / AFTER ENTRY 条件跳转仍生效）；
   **带小数的字段（如 ###.#）回车后自动补齐小数**（170 → 170.0，位数来自 .qes 占位符）；
   **整数字段自动去前导零**（个人编号 0103120237 → 103120237、00 → 0，
   与原版 EpiData 录入行为一致）；
   **日期输 20261122 回车后自动变为 2026/11/22**；输满自动跳下一格；
   **MUSTENTER 必填字段空着离开时立即弹窗拦截**（当场填，不拖到保存），
   被跳转合法跳过的必填允许留空（与 EpiData 语义一致）；
   输入不合法时**弹窗提示**，Enter 关闭后重新输入。全程支持纯键盘
   （Enter/Esc/方向键/Ctrl+Enter）。
   **回溯即修改模式**：方向键回到已填的格子时内容自动全选，直接打字即覆盖。
   底部状态栏实时显示当前格子的字段名、类型与范围、存储长度。
   录入页工具栏：**◀ 上一份 / 下一份 ▶ / ＋ 新增 / 删除**，可随时翻看其他问卷
   （编辑保存同样直接写回 .rec）；查看其他问卷不影响正在录入的草稿，
   **「↩ 回到当前正在录入的问卷」**一键回原位续录；切到别的页面再回来
   也自动回到光标原位。删除前自动生成完整备份 `.deleted-*.bak`。
   **草稿续录**：每填一格自动写入伴生草稿文件 `<rec名>.draft.json`（半条记录不写入
   .rec 以免产生空记录）；中途退出后再次打开同一 .rec 会询问是否从上次位置继续；
   整份问卷保存进 .rec 后草稿自动清除。保存直接写入 .rec（自动备份 .bak），
   保存后自动开始下一条。
3. **浏览**：Excel 式全字段表格（全部记录 × 全部字段，表头行与行号列冻结、
   隔行底纹、列头悬停显示题目全文、双击记录进入编辑），支持全文过滤；
   **「检查历史数据并规范化」**按钮：扫描全部记录的数值字段（去前导零、
   按定义小数位格式化），先报告差异与问题、由用户确认后执行；
   无法解析/超格式的值保持原样并报告，绝不破坏历史数据（执行前自动 .bak）。
4. **导出**：导出面板完整复刻 Windows EpiData 的「将REC文件导出为text文件」对话框，
   且**记录范围 / 字段选择 / 编码对三种格式（text / xlsx / csv）全部生效**：
   - 记录号范围、字段勾选（全选/不选、悬停显示题目、**点选锚点后可
     「此字段及之前 / 此字段及之后」批量选择**）、记录过滤器（`a03=2 and z1=1`）
   - 选项：文本括号 `"`、分割符（; , Tab 空格）、首行字段名（仅 text）；
     **导出编码可选 GBK（兼容 GB2312，Windows 默认）/ UTF-8 / UTF-8 带 BOM**，
     xlsx 内部为 XML 无编码问题
   - 导出位置 = 「选择文件夹」+「文件名」；导出顺序与 EpiData 原生导出逐列一致
     （测试锁定）。

写回的 .rec 保持原格式（GBK 编码、CRLF、`!` 行终止符、78 字符断行），
Windows EpiData 可直接打开/合并。

## 文件格式（逆向结论，已字节级验证）

详见 `epirec.py` 模块 docstring。要点：

- `.rec` = 纯文本（GBK/CRLF）：首行 `<定义行数> 1 VLAB`；N 行字段定义
  （`#`/`_` 前缀 + 行列/类型/宽度 + 问题文本，`_labelN` 为标题不占记录空间）；
  数据区每条记录固定「字段宽度之和」字节，按 78 字符断行、每行 `!` 结尾。
  数值右对齐补空格、字符串左对齐补空格。
- `.qes` = 问卷版面：`{字段名}` + `#`/`_`/`<yyyy/mm/dd>` 占位符；无花括号的
  占位符由 EpiData 按行首单词自动命名（如 `Z8 录入日期：<yyyy/mm/dd>` → z8），
  兜底名 `fieldN`。
- `.chk` = 每字段一块的缩进规则块。

字段与版面的绑定规则：.rec 定义行的行号 → .qes 行，行内从左到右按宽度对齐。

## 测试

测试需要一份真实的 EpiData 项目数据（.rec/.qes/.chk），通过环境变量指定目录：

```bash
export EPIDATA_TEST_DATA=/path/to/your/epidata/project   # 含 .rec/.qes/.chk
python tests/test_roundtrip.py    # .rec 字节级还原 + 与原版导出 txt 交叉核对
python tests/test_qes_chk.py      # 绑定与规则解析自检
python tests/test_save_flow.py    # 端到端增改存（在 /tmp 副本上进行；需服务已启动）
python tests/test_export.py       # 导出与原版 EpiData 导出逐列比对（只读；需服务已启动）
```

test_export 支持两个可选环境变量：`EPIDATA_REF_TXT`（原版 EpiData 导出的 txt，
用于表头顺序比对）、`EPIDATA_REF_XLSX`（人工汇总的 xlsx，用于逐格比对）。
未设置数据目录时测试自动跳过。

## 已知限制

- .chk 仅支持 RANGE / LEGAL / MUSTENTER / REPEAT / JUMPS / AFTER ENTRY..GOTO；
  其它命令（HELP、CONFIRM 等）会收集为警告展示，不影响打开与保存。
- 不支持从 .qes 新建空 .rec（打开已有 .rec 即可，0 条记录也行）。
- 双录入核对未实现（按需求暂缓）。
- 仅在 macOS 上测试（文件夹/文件选择对话框依赖 osascript）。
